# Lesson-aware Studio behavior

## Lesson metadata

The Studio should understand:

- lesson title
- description
- active built-in profile
- world file
- goal definition

## Lesson-aware help

Show only the current lesson’s available built-ins and concepts. Do not flood early learners with the full language surface.

## Goal panel

Should display:

- current objective
- completion state
- optional hints
- optional ideal constraints later

See [`AGENTS.md`](../../AGENTS.md) (built-ins and lesson rules).
