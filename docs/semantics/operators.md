# Operators (semantics)

Operator set for typing and lowering:

## Unary

- `-`
- `!`

## Binary arithmetic

- `+`
- `-`
- `*`
- `/`

## Comparison

- `==`
- `!=`
- `<`
- `<=`
- `>`
- `>=`

## Boolean

- `&&`
- `||`

## Recommendation

Do **not** add string concatenation in the first pass — little gain, muddier model.

Lexical form: [../language/lexer.md](../language/lexer.md).
